Claude Sonnet 5.5

Модель Anthropic среднего уровня, которая работает в приложении Claude, через API и во многих рабочих инструментах.

Где Sonnet 5.5 в линейке

Модели Claude делятся на уровни. Haiku самая компактная и быстрая, Sonnet занимает середину, Opus мощнее. Выше Opus стоит новый уровень Mythos. Sonnet 5.5 рассчитан на повседневную работу: тексты, анализ, код, учёба.

Что с ней можно делать

  • Писать и редактировать тексты, переводить, объяснять сложные темы.
  • Разбирать фотографии и документы: например, школьные карточки с заданиями.
  • Писать и исправлять код, анализировать данные.
  • Искать в интернете свежую информацию, когда включён поиск.
  • Создавать файлы, страницы и небольшие приложения, как эта страница.

Где её найти

Sonnet 5.5 доступен в веб-версии, мобильном и настольном приложении Claude. Для разработчиков есть API и платформа Claude. Модель работает и в других продуктах Anthropic:

  • Claude Code для программирования из командной строки.
  • Claude Cowork для рабочих задач без кода.
  • Claude in Chrome, Excel и PowerPoint для работы в браузере, таблицах и презентациях.
  • Claude Tag для вызова Claude прямо в Slack.

Актуальные цены, лимиты сообщений и новые функции меняются. Их лучше смотреть в документации на docs.claude.com и support.claude.com.
